# Althaf Jewellery Makers — Frontend Application

A React Single Page Application (SPA) built with **React 18** and **Vite** for **Althaf Jewellery Makers** (Heritage Luxury Indian Jewellery, Guntur AP).

---

## 🚀 Quick Setup & Execution

1. **Navigate to the frontend folder**:
   ```bash
   cd frontend
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser at: `http://localhost:3000/`

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```

---

## 🛠 Available Scripts

| Command | Description |
| :--- | :--- |
| `npm run dev` | Starts Vite dev server at `http://localhost:3000/`. |
| `npm run build` | Builds production bundle into `dist/`. |
| `npm run preview` | Previews production build locally. |
